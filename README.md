# 🍰 مشروع حلويات

## 📖 نبذة عن المشروع
مشروع **حلويات** هو موقع إلكتروني مخصص للتعريف بوصفات الحلويات وتقديم أفكار متنوعة وسهلة التحضير في المنزل. يهدف المشروع إلى جمع الوصفات في مكان واحد ومساعدة الزوار على اكتشاف حلويات جديدة وتجربتها.

## 🎯 أهداف المشروع
- تقديم وصفات حلويات متنوعة وواضحة.
- عرض مكونات كل وصفة ومقاديرها.
- شرح خطوات التحضير بطريقة سهلة ومنظمة.
- مساعدة الزوار على اختيار وصفات تناسب أذواقهم ومناسباتهم.

## 🧁 محتوى الموقع
يتضمن الموقع وصفات وأفكارًا مثل:
- الكيك والطورطات.
- الحلويات التقليدية.
- البسكويت والحلويات الصغيرة.
- حلويات المناسبات.
- وصفات سهلة وسريعة التحضير.

## 💻 التقنيات المستخدمة
- **HTML** لبناء صفحات الموقع وتنظيم المحتوى.
- **CSS** لتنسيق الصفحات وتحسين شكل الموقع.
- **JavaScript** لإضافة التفاعلات والميزات عند الحاجة.

## 🚀 خطة التطوير
سيتم تطوير المشروع تدريجيًا بإضافة صفحات الوصفات والصور والمقادير وطرق التحضير، مع تحسين التصميم وسهولة الاستخدام.

## 📌 حالة المشروع
المشروع قيد التطوير والتعلّم.
