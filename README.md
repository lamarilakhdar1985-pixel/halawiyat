# 🍰 مشروع الحلويات

## نبذة عن المشروع
موقع عربي لوصفات الحلويات والكيك، يهدف إلى جمع الوصفات في مكان واحد، مع إضافة المقادير وطريقة التحضير والصور تدريجيًا.

## ملفات المشروع الحالية
- `index.php`: الصفحة الرئيسية، وبها قائمة الأقسام والوصفات المقترحة وروابط الصفحات الأخرى.
- `assets/css/style.css`: تنسيق الصفحة الرئيسية والتصميم المتجاوب للهواتف والحواسيب.

## تشغيل المشروع محليًا
يحتاج المشروع إلى خادم يدعم PHP. بعد تثبيت PHP وفتح الطرفية داخل مجلد المشروع، شغّل:

```bash
php -S localhost:8000
```

ثم افتح هذا العنوان في المتصفح:

`http://localhost:8000`

> لا تفتح ملف `index.php` بالنقر المزدوج؛ يجب تشغيله من خلال خادم PHP حتى تُنفّذ أوامر PHP.

## الصفحات المقترحة للإضافة لاحقًا
أنشئ هذه الملفات في المجلد الرئيسي للمشروع حتى تعمل الروابط الموجودة في الصفحة الرئيسية:

- `recipes.php` لعرض الوصفات، ويمكنه استقبال اسم القسم عبر `?category=cakes`.
- `recipe.php` لعرض وصفة واحدة، ويستقبل رمزها عبر `?slug=gateau-vanille`.
- `search.php` لمعالجة البحث، ويستقبل عبارة البحث عبر `?q=...`.
- `about.php` لصفحة من نحن.
- `contact.php` لصفحة اتصل بنا.

روابط الصفحات الإضافية موجودة في `index.php)، وستعمل بعد إنشاء ملفاتها. حاليًا الصفحة الرئيسية والتصميم جاهزان، أما صفحات التفاصيل والبحث فلم تُنشأ بعد.

## التقنيات
- PHP لبناء الصفحات وإضافة المحتوى المتغير.
- HTML لتنظيم المحتوى.
- CSS للتصميم ودعم الشاشات الصغيرة.
- JavaScript يمكن إضافته عند الحاجة.

## حالة المشروع
المشروع قيد التطوير، وسيتم إضافة صفحات الوصفات والوظائف تدريجيًا.
